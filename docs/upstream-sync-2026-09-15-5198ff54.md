FC-003's original equivalent-isolation retirement condition is superseded by
the approved removal of the guarded behavior itself. Its dedicated state tests
are obsolete; successful attachment, size refusal, placeholder paths, filesystem
permissions and notebook metadata are still tested by their owning suites.

Main had already repaired the historical full-context capture defect. Removing
model creation is an upstream ownership-policy alignment, not a claim that the
fork's implementation remained broken. FD-009 still protects the checkpoint
writer, session-ask forkQuery and runtime-created persistent recovery. Shared
runtime full-context code must not be deleted when narrowing the model schema.

The generic shell wrapper's existing mixed `{script, ...outerFields}` policy is
unchanged. Context rejection is verified for canonical operation JSON, script
flags and supported no-script recovery; it is not a claim about every malformed
mixed object. Compat must preserve values through recovery before validating
them, rather than silently dropping valid or malformed context fields.

History indexes all supported content, removes kind selection and the legacy
history config surface, and commits imported source/index state transactionally.
Migration progress survives interruption and records completion. Once complete,
startup deliberately does not rescan every session; an index write lost later
is not guaranteed to repair merely by reopening. This accepted upstream limit
is not a general durable-index repair guarantee.

The extra history correction keeps raw JSON escapes until final parsing, so old
SQLite does not truncate NUL-containing text. Only a disposable decoded-byte
counting copy substitutes an equal-size control character. Tests cover both
sides of 4,000 bytes, multibyte text, literal escape sequences, complete retrieval
and unchanged stored data.
