# 同步证据与知识归属

记录服务于复核和接续执行。只填写实际获得的证据；未完成项明确写 `pending`、失败原因和下一步，不能用计划中的验证填充结果。

## 规范从哪里来

| 来源 | 保留的作用 | 不应沿用的内容 |
| --- | --- | --- |
| 用户当前请求和既有授权 | 范围、目标、冻结/只读条件、发布与清理授权 | 把“评估是否可删除”扩大为删除 |
| 目标提交的 AGENTS 与 FD/FC/DC | fork 流向、命令、当前行为边界及归属 | 用某次旧登记替代当前实现 |
| 本技能及按需参考文件 | 同步、验证、发布和可恢复清理流程 | 新建重复的全局规范副本 |
| 历史 fork 同步记忆技能 | 精确 SHA、环境污染、语义合并、锁文件/构建等失败线索 | 旧 fetch 命令、旧超时值、旧 CI 分片或旧完成 SHA |
| PR 审查与历史运行记录 | 范围隔离、讨论逐条裁定、证据失效原因 | 过去的绿灯、旧工作树状态、曾经的功能缺失 |
| 当前工作树与工具输出 | 当次状态、可重复验证、备份与清理结果 | 将个人机器配置或临时路径固化为通用示例 |

个人记忆不是运行依赖，不复制整段 rollout，也不因本次整理自动更新个人记忆文件。更新记忆须有用户明确请求。技能是流程规范；每次同步的能力清单和历史证据放在仓库的同步记录与登记历史中。

## 每次同步的记录字段

按需使用现有仓库记录，避免重复创建报告。至少包含：

- **范围**：full / specified / frozen；审计或执行；用户授权的目标分支、冻结或禁止 ref 变化条件。
- **不可变基线**：选定 upstream/源 SHA、起始 main/compat SHA、允许的 fetch 和实际刷新时间。指定变更列出明确排除项。
- **资源台账**：主工作区原状态、操作创建的路径/分支/临时 refs、需保护的旧资源；后续独立清理授权另记。
- **能力清单**：N、每项 ID、生产者/调用者/测试、两支对应实现、共享或 compat owner、FD/FC/DC、关系、行为/schema/命名等漂移、处置和证据。
- **验证矩阵**：branch/source SHA、能力/契约、命令与 package cwd、环境/preload、进程/分片边界、实际测试数量/退出状态、日志、证据覆盖限制。
- **审查与登记**：审查绑定的 head、未决反馈及技术裁定；源码/测试与指导内容快照，纯文档更新不伪装成运行时修复。
- **发布证据**：最终 main/compat SHA；所需各 workflow 的 run URL、headSha 和结论；远端 tip、祖先或排除证明。审计模式明确不发布。
- **收尾**：本地分支是否安全快进、原有修改是否保留、操作资源是否移除、备份与保留项；并行累计时间与墙钟时间分开。

## 最终结果表

每个清单 ID 恰好一行，结果行数必须等于 N。下列为字段约定，不能把示意行当作已经完成的能力：

| ID | 选定行为 | main 结果 | dev/compat 结果 | 决定性路径/测试/证据 |
| --- | --- | --- | --- | --- |
| C01 | 一项可观察行为 | 采用/适配/保留/待处理 | 继承/适配/未作为目标 | 对应实现、测试和实际结论 |

处置表与发布状态分开：清单完整、语法绿、局部运行通过、已推送、最终 CI 通过、当前远端对齐是不同结论。任何缺少的完成条件都应保留为未完成；指定变更或冻结审计不能宣称与最新 upstream 完全同步。

## 维护本技能时

优先将高频决定放在入口、条件性细节放在引用文件。新增内容应对应真实失误或已识别的检索/操作缺口，避免累积一次性超时数字、PR 号或机器路径。

验证 frontmatter、引用可达性、范围与授权一致性，再以独立场景检查实际决策。静态 lint 不证明行为改善；基线已正确时，只报告规范补齐和新场景结果，不宣称性能或正确率提升。文件已写入、客户端已发现、已加载、已提交和已发布也应分别报告。
